# Статус Нейры

## Активные подсистемы
- ✅ Метрики обучения
- ✅ Адаптивная сложность
- ✅ Чат-интерфейс
- ✅ Автопилот

## Текущие возможности
- Диалог через веб-интерфейс
- Сбор и визуализация метрик
- Автоматическая адаптация сложности
- Сохранение прогресса обучения

## Как использовать

### Базовые команды
- "привет" - начало диалога
- "как дела?" - получить текущее состояние
- "статус" - подробный отчет о системе

### Метрики
- current_difficulty - текущий уровень сложности
- learning_attempts - количество попыток
- learning_success_rate - процент успешных ответов

### Управление
1. Запуск: `run.bat`
2. Веб-интерфейс: http://localhost:9090
3. Логи: `logs/neira.log`
